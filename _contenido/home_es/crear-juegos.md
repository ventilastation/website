heading: ¿Cómo hacer juegos para Ventilastation?
---
Podés hacer tu primer juego circular con MicroPython y **VS2**, la API actual,
sin tener una consola física. La documentación está en inglés.

1. [Prepará el emulador de escritorio](/docs/guides/desktop.html).
2. [Creá tu primer juego y mové una nave](/docs/vs2/tutorial/first-game.html).
3. [Seguí el tutorial completo](/docs/vs2/tutorial/index.html) para agregar enemigos, puntaje y sonido.

También podés [jugar y probar cambios en el navegador](/docs/guides/browser.html)
sin instalar nada. Para consultar una clase o método, usá la
[referencia de la API](/docs/vs2/reference/index.html).

Después del tutorial, [Vyruss VS2](https://github.com/ventilastation/vsdk/blob/main/games/alecu/vyruss_vs2/code/vyruss_vs2.py)
es un ejemplo de un juego completo. La API antigua `ventilastation.sprites` es
obsoleta para juegos nuevos y tiene una sección aparte para mantenimiento.
