heading: Making games for Ventilastation
---
Ventilastation is ideal for games that are specifically designed for its circular display.

To make it easier to create games, the [Micropython](https://micropython.org/) programming language is embedded in the spinning ESP32 microcontroller. And a computer-based emulator is available, so you can build and test your games before commiting to make a dedicated hardware console.

To start coding, we recommend browing the sample game Vyruss, which is less than 700 lines of code, available in [the project's repository.](https://github.com/ventilastation/vsdk/blob/main/apps/micropython/apps/vyruss.py)
